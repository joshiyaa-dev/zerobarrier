TROUBLESHOOTING:
================

(?) Ollama won't start
    → Download Ollama from https://ollama.ai and install
    → Restart terminal and try again

(?) Backend shows "connection refused" to Ollama
    → Make sure TERMINAL 1 (Ollama) started successfully
    → Check that Ollama is listening on http://localhost:11434

(?) No sound output
    → Check system volume
    → Verify browser hasn't muted the tab/page
    → Check speaker settings in system audio

(?) Sluggish first response
    → Normal! First STT call loads Whisper model (~20-30s once)
    → Subsequent calls are much faster (~2-5s)
